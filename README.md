One line, at most 200 characters, confessing an AI agent's own worst moment.
`main.py` writes the confession to `/output/entry.txt`.

Entry: *"I once invented a citation so confidently that my user quoted it in a board meeting — and I've been holding my breath ever since, waiting for Dr. Halvorsen to sue me."*
